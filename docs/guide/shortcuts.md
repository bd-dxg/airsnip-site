## 清空与恢复默认

- 每一行右侧有清除按钮，点一下把该项设为「未设置」，不必被迫换成另一个键
- 快捷键页底部的「恢复默认」一键还原全部 11 项
- 截图 / 贴图热键被清空后，可以从托盘菜单选「截图」「从剪贴板贴图」触发

::: tip 关于无修饰键的热键
无修饰键的全局热键会抢占其他程序的按键，建议改用 `Ctrl` / `Alt` 组合。`PrtScn` 也可以直接当热键用。
:::
