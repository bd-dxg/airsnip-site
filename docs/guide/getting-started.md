# 快速上手

AirSnip 是绿色单文件，解压即用，不写注册表。下面是完整启动流程。

## 1. 下载并解压

点击下载按钮获取 zip（约 0.89 MB，含文档与许可证），解压到任意目录。

<DownloadCard />

## 2. 双击 airsnip.exe

管理员账户会弹一次 UAC 确认提权（这样才能截到管理员权限的窗口），选「是」；标准账户（公司 / 学校统一管理、拿不到 UAC 凭据）不弹 UAC，直接以普通权限运行，代价是截不到以管理员身份运行的程序窗口，启动时会弹一次托盘气泡说明原因。

::: tip 首次运行提示
如遇 Windows SmartScreen 提示，点「更多信息」→「仍要运行」。
:::

## 3. 托盘常驻

启动后没有主窗口，程序常驻托盘：按 `F1` 截图，按 `F3` 贴图。热键被清空或与别的程序冲突时，也可以用托盘菜单的「截图」「从剪贴板贴图」。

## 4. 打开设置

托盘图标左键打开设置，右键是「设置 / 退出」。

## 5. 配置文件

配置写在 `%APPDATA%\airsnip\config.toml`。

## 关于更新

启动后会自动检查新版本，发现时弹托盘气泡；也可以在设置 → 「关于」页手动更新。不需要的话，在那里关掉「启动时自动检查」。

## 关于热键

默认 `F1` 截图、`F3` 贴图，可在设置里修改。没有修饰键的全局热键会抢占其他程序的按键，建议用 `Ctrl` / `Alt` 组合。
