# 常见问题

## AirSnip 会联网吗？

不会。截图与标注全部在本地处理，不联网、不上传、无遥测。

## 怎么卸载？

删除 exe 即可，程序不写注册表；开机自启走任务计划，可以在设置里关掉「开机自启」。

## 怎么改热键？

托盘图标左键打开设置 → 「快捷键」页，全部快捷键可改，带冲突检测与输入法兼容。默认 `F1` 截图、`F3` 贴图。

没有修饰键的全局热键会抢占其他程序的按键，建议用 `Ctrl` / `Alt` 组合。

## 配置文件在哪？

`%APPDATA%\airsnip\config.toml`

## 为什么首次运行会弹 UAC？

程序需要管理员权限，否则无法覆盖管理员权限的窗口。首次运行弹 UAC 时选「是」。

## 截图保存成什么格式？文件名怎么定？

另存为支持 PNG / JPEG / WebP（无损）；也可以直接复制到剪贴板，粘到微信 / 文档 / 聊天框不失真。

文件名模板可选 `airsnip-20241231-235959`、时间戳、仅日期，程序会记住上次的目录与格式。

## 贴图最多几张？

最多 20 张，可以一键全部关闭。
