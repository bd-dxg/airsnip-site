# 常见问题

## AirSnip 会联网吗？

截图、标注、长截图拼接、贴图全部在本地处理，不上传截图、无遥测。唯一会联网的是自动更新：启动后静默检查新版本（可关，见下一条），只是查版本，不会上传任何内容。

## 怎么更新到新版本？

启动后会静默检查，发现新版本时弹托盘气泡；也可以打开设置 → 「关于」页，点「更新到 vX.Y.Z」下载并自动替换重启。

检查与下载优先走国内加速镜像，GitHub 直连兜底；清单用 ed25519 签名 + SHA-256 双重校验，验签不过不会安装。不需要自动检查时，在「关于」→ 版本更新里关掉「启动时自动检查」。

从 v0.7.0 开始才支持自动更新，更早的版本需要手动下载一次新版 zip。

## OCR 怎么开？

OCR 默认关闭。打开设置 → 「OCR 翻译」里的总开关后，截图时工具栏会出现 OCR 按钮，覆盖层里也可以按 `T`。识别走 Windows 自带的 OCR 引擎，图片不出本机。

## 怎么卸载？

删除 exe 即可，程序不写注册表；开机自启走任务计划，可以在设置里关掉「开机自启」。

## 怎么改热键？

托盘图标左键打开设置 → 「快捷键」页，全部快捷键可改，带冲突检测与输入法兼容。默认 `F1` 截图、`F3` 贴图。

每一项右侧的清除按钮可以把按键设为「未设置」，不再需要时不必换成另一个键；页面底部「恢复默认」一键还原。截图 / 贴图热键被清空后，可以从托盘菜单选「截图」「从剪贴板贴图」。

没有修饰键的全局热键会抢占其他程序的按键，建议用 `Ctrl` / `Alt` 组合。

## 配置文件在哪？

`%APPDATA%\airsnip\config.toml`

## 为什么首次运行会弹 UAC？

程序需要管理员权限，否则无法覆盖管理员权限的窗口。首次运行弹 UAC 时选「是」。

## 截图保存成什么格式？文件名怎么定？

另存为支持 PNG / JPEG / WebP（无损）；也可以直接复制到剪贴板，粘到微信 / 文档 / 聊天框不失真。

文件名模板可选 `airsnip-20241231-235959`、时间戳、仅日期，程序会记住上次的目录与格式。

## 贴图最多几张？

最多 20 张，可以一键全部关闭。
