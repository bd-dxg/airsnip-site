# 功能详解

## 截图 {#capture}

`F1` 触发：全屏冻结后进入框选。

- 八向缩放，按住空格整体拖动选区，方向键 1px 微调（按住 `Shift` 每次 5px）
- 窗口吸附：还没框选时，光标停在哪就在哪高亮，单击就把整个窗口定成选区；停到工具栏按钮、输入框这类控件上会继续下钻，高亮那个控件本身，滚轮可上下调整捕捉层级
- **框选完成后默认是「移动选区」**：选区内拖空白整体平移（标注跟着走），拖对象移动那个标注；要画标注先选工具（工具栏第一个「移动」按钮，或按 `V`）
- 没有选区时按 `F` 选中光标所在显示器的整屏（含任务栏，多显示器下鼠标在哪块屏就框哪块），按 `R` 复用本次运行上一次确定的选区；两者都只选中、不自动完成
- `Shift+F1` 再次截图：不退出覆盖层，重新冻结屏幕再框选；上一次的覆盖层控件也会被截进新图里
- 选区内空白处双击 = 复制完成（可在设置里改成直接贴到屏幕）
- 多显示器与负坐标布局正确（Per-Monitor V2）
- `F1` 被清空后，也可以从托盘菜单选「截图」触发

## 标注 {#annotate}

框选完成后默认是移动态，点工具栏的工具或按数字键才进入绘制，按 `V` 回到移动态。按键可改。

颜色组是 2 个纯色 + 1 个渐变：渐变块上单击就使用，双击换一套（24 套，一套为跨 360° 的完整光谱，在 OKLab 感知空间插值、首尾闭合，描边绕一圈不留硬接缝）。「填充」右侧是线型格子，实线 / 虚线 / 点划线三档，段长随线宽缩放；线型是对象样式，选中标注后改立即生效并记一次撤销，没选中时只影响下一次绘制。

序号工具升级成**徽标**，内容三态是数字、对勾、叉号，用来标「这里对、这里错」。序号格子右下角多了个 `▾`，点开是三行下拉；符号不占编号，一张图里混放 `1`、`✓`、`✕`、`2` 仍是 1、2。符号用矢量描边画，换任何字体都不会变成豆腐块，和徽标的圆形比例也始终一致。放置后要改：对勾 / 叉号徽标双击在两者之间切换（一次 `Ctrl+Z` 可回退），编号徽标双击仍进编辑框，直接打 `v` / `√` / `✓` 或 `x` / `×` / `✕` 即可，不需要输入法。

## 二次编辑 {#edit}

- 选中对象显示包围框 + 八向手柄：拖动移动、拖角缩放（`Shift` 等比）
- 绘制态下要挪已有标注：按住 `Ctrl` 拖对象本体，或拖它的包围框边缘；移动态下直接拖就行
- 平移选区（拖动或方向键）时标注一起跟随，拖手柄缩放只改裁剪范围
- 选中后按 `Del` / `Backspace` 只删这一个标注，`Ctrl+Z` 一步恢复，不连带撤销其它标注
- 颜色与填充实时作用于选中对象；线宽 / 模糊强度 / 字号用滚轮调
- 撤销 / 重做 100 步，一次拖拽 = 一步

## 输出 {#output}

- 剪贴板：`CF_DIB` + 延迟渲染 PNG，粘到微信 / 文档 / 聊天框不失真
- 另存为：PNG / JPEG / WebP（无损），按 `Ctrl+S`（可改键）
- 快速保存：`Alt+S` 按保存路径模板直接落盘、不弹对话框；存完弹一条轻提示，点提示直接定位到文件，可选同时复制到剪贴板
- 保存路径模板：目录（点一下用资源管理器选）+ 文件名 + 格式（png / jpg / webp），支持 `$yyyy$ $yy$ $MM$ $dd$ $HH$ $mm$ $ss$ $ts$` 与 `%VAR%`；同名自动加序号，目录不存在自动创建，模板写坏会在写盘前拦住

## 长截图 {#longshot}

- 以当前选区为视口，自己滚动页面，`Enter` 收尾，`Ctrl+Z` 撤销最后一段
- 逐行切 8 段各算哈希，5 段一致就算这行没变：页面里有轮播图、GIF 头像、闪烁光标、进度条这类局部动画也不会整段失败
- 重叠区最小要求放宽到内容区的 1/5，快速滚动（超过半屏）也能接上；所有候选位移都参与打分取最优
- 白底 / 内容稀疏的页面不再一滚动就被判「静止」
- 吸顶导航、底部工具栏、左右粘滞侧栏只留在最上面（最左）一份，纯色列不会被误遮
- 拼接过程实时缩略预览
- 失败不丢内容：参考帧只跟着成功拼入的部分前进，滚太快定位失败时往回落一点就能接上
- 完成后状态条有「另存为」按钮，也可以按 `Ctrl+S`：自选路径与格式（PNG / JPEG / WebP），文件名与目录按保存路径模板预填；不另存时仍按模板自动保存
- 日志默认就在写：设置 →「通用」页底部点「打开日志文件夹」拿到 `%TEMP%\airsnip\` 下的 `airsnip-longshot.log`，只有状态文本（滚动位置、匹配得分、画面变化比例），不含页面内容；超过 4MB 自动轮转，定位异常时会把两帧画面存成 PNG（每次运行最多 6 对）

## 贴图（Pin） {#pin}

- `F3` 把选区（含标注）钉在屏幕上
- 拖动、滚轮缩放、`Ctrl`+滚轮调透明度、1px 蓝框、右键菜单
- 最多 20 张，可一键全部关闭

## 设置 {#settings}

- 自绘面板，跟随系统深浅色
- 界面语言：简体中文 / 繁體中文 / English / 日本語（设置 → 「通用」），默认跟随系统，不支持的系统语言回落 English；选完立即生效，界面不重开。界面文案全部编译期嵌入，标注内容的字体不跟界面语言变
- 「外观」设置：调整软件主题，支持跟随系统切换、自适应；界面缩放可选自动或 100%–200% 固定档位，作用于全部界面（设置面板、覆盖层工具栏、贴图窗口）
- 「工具栏」页：24 个元素逐项显隐（移动 + 10 个工具、3 个色块、填充·线型·撤销·重做·字体行、贴图·长截图、复制·快存·保存），组头可整组全显或全隐；隐藏只影响绘制，快捷键与输出照旧——藏了保存按钮，`Ctrl+S` 照样能存
- 开机自启、「连按两次 Esc / 右键退出」、窗口吸附与控件级捕捉（默认都开，关掉后行为与旧版一致）
- 「通用」页底部有「打开日志文件夹」，长截图出问题时直接打开 `%TEMP%\airsnip\` 拿日志报障
- 快捷键页分「截图 / 输出 / 工具」三页，共 20 项，全部可改（含冲突检测与输入法兼容）；每一项都能清空为「未设置」，底部「恢复默认」一键还原全部快捷键
- 贴图默认位置（一行开关：开 = 屏幕中间、关 = 原位置）、双击选区空白的动作（复制 / 贴图）、保存路径模板、主题；开关点完立即生效并写盘
- 自动更新：启动后静默检查新版本，发现后弹托盘气泡；可以在「关于」→ 版本更新里关掉「启动时自动检查」，也可以在那里手动更新
- 「关于」页：版本、许可、「官网·永久免费」渠道、第三方组件清单、项目地址，以及「我要反馈」——一键把版本号、Windows 版本、显示器与显卡信息写进剪贴板（不收集用户名、保存路径与截图内容）；底部标明软件免费，从第三方购买请向卖方申请退款
