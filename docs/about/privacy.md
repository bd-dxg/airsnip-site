# 隐私说明

## 软件

- 截图、标注、长截图拼接、贴图都在本地完成，不上传截图、无遥测
- 唯一的联网行为是自动更新：启动后访问 GitHub Releases（或其国内加速镜像）检查新版本，只查版本号与清单，不上传任何内容；可在设置 → 「关于」→ 版本更新里关掉「启动时自动检查」
- 配置文件只写在本机 `%APPDATA%\airsnip\config.toml`

## 本网站

本站是纯静态页面：不使用统计脚本，不加载网络字体与 CDN 资源，也不会自动发起任何第三方请求。

下载按钮是你主动点击的跳转：一个指向 GitHub，一个指向国内加速站（只转发 GitHub 的文件，内容一致）。
