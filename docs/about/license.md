# 开源与许可

AirSnip 以 **GPL-3.0-only** 开源，源码与问题反馈都在 [GitHub 仓库](https://github.com/bd-dxg/airsnip)。

- 许可证全文：[LICENSE](https://github.com/bd-dxg/airsnip/blob/main/LICENSE)
- 第三方组件清单：[THIRD-PARTY.md](https://github.com/bd-dxg/airsnip/blob/main/THIRD-PARTY.md)
- 问题反馈：[Issues](https://github.com/bd-dxg/airsnip/issues)

第三方依赖均为宽松许可证（MIT / Apache-2.0 / BSD / Zlib / IJG 等）。
