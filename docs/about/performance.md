# 性能数据与口径

下表是作者在自己目标机型上的实测值，不同环境会有差异，不构成性能保证。

| 指标 | 数值 | 说明 |
| --- | --- | --- |
| 单文件体积 | 1.21 MB | 一个 exe 就是全部 |
| 下载包 | 0.67 MB | zip，含文档与许可证 |
| 待机内存 | 1.2 MB | 常驻托盘时 Private Working Set |
| 待机 CPU | 0.00% | 事件驱动，无定时轮询 |
| 热键 → 可用画面 | 124 ms | 2560×1440：全屏抓取 + 暗化 + 覆盖层就绪 |
| 拖框重绘 | 4.6 ms / 帧 | 60 FPS 红线 16.7 ms，约 3 倍余量 |

::: info 口径说明
截图会话期间按屏幕大小临时分配位图（1440p 约 15 MB），退出覆盖层立即释放。

待机内存按 Private Working Set 计量。任务管理器「内存」列显示的是工作集，包含与其他进程共用的页，同一状态会看到约 5–10 MB，两个数字不矛盾。

测试环境为 2560×1440、无独立显卡的目标机型。原始记录见
[perf-m5.md](https://github.com/bd-dxg/airsnip/blob/main/docs/perf-m5.md)。
:::

## 为什么能这么小

- 没有 Electron / WebView / .NET 运行时；界面与标注由 Rust 直接绘制；常驻部分只做「等热键」。
- 同类工具常见自带运行时或基于 Electron，安装包数十至上百 MB、常驻内存数百 MB 量级。
- 不靠 GPU：纯 CPU 渲染，核显迷你主机、虚拟机、远程桌面里同样流畅。
- 本地处理：截图与标注在本机完成，不上传、无遥测；只有检查新版本时会联网。

## 技术栈

Rust（edition 2024）、windows-rs、tiny-skia（矢量栅格化）、DirectWrite（文字）、GDI BitBlt（抓屏）。
